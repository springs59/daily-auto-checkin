# 自动签到使用说明

## 1. 安装应用

1. 从 GitHub Actions 的最新成功运行中下载 `app-universal-release-apk`。
2. 解压下载的 artifact，得到 APK 文件。
3. 将 APK 传到 Android 设备并安装；系统提示时授予安装未知应用权限。
4. 首次打开应用后，允许通知权限。需要长期后台运行时，在系统设置中允许后台活动并关闭电池优化。

## 2. 添加站点

1. 打开“站点”页，点击右下角“添加”按钮。
2. 填写站点 JSON。`id` 用于关联账号且保持唯一；`name` 为展示名称；`checkin.url` 为个人账号有权使用的签到接口地址。
3. 在 `headers` 或 `body` 中使用 `{{token}}` 作为账号凭证占位符。
4. 保存后在站点列表启用该站点。

应用仅根据已配置的请求执行签到。接口地址、请求方法、请求头、请求体与成功判定应来自目标服务提供的授权接口资料。

## 3. 添加账号

1. 打开“账号”页，在顶部选择站点。
2. 点击右下角“添加”按钮。
3. 输入账号名称和对应站点的登录凭证或令牌，保存并启用账号。
4. 凭证会替换站点 JSON 中的 `{{token}}` 占位符。

## 4. 测试和定时签到

1. 打开“总览”页并点击“立即签到”。
2. 在“日志”页查看每个账号的结果并修正站点配置。
3. 开启后台自动签到服务和每日定时签到，设置执行时间。
4. 保持系统通知权限和后台运行权限，设备重启后应用会恢复已开启的服务。

## 5. 管理站点和账号

- 自定义站点可编辑、启用、停用或删除。
- 删除自定义站点会同时删除该站点的关联账号。
- 内置站点支持编辑和恢复默认配置。
- 账号页支持编辑、启用、停用或删除账号。

## 6. 导入和导出配置

1. 在“账号”页点击“导出配置”，使用系统文件选择器保存 JSON 文件。
2. 导出文件包含自定义站点、内置站点覆盖、账号凭证和定时设置。
3. 在另一台设备的“账号”页点击“导入配置”，选择此前导出的 JSON 文件。
4. 导入会合并站点和账号；导入账号会创建新的本地 ID。

导出文件包含登录凭证。将文件保存在受信任的位置，传输后及时清理副本。
